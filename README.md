# ครามสเตย์ สกลนคร — ระบบจองห้องพักในเขตอำเภอเมืองสกลนคร

> **ขอบเขตของระบบ**
> - รับเฉพาะที่พัก 4 ประเภท: **โรงแรม · อพาร์ทเม้น · หอพัก · รีสอร์ท**
> - รับเฉพาะที่พักที่ตั้งอยู่ใน **เขตอำเภอเมืองสกลนคร** เท่านั้น
> - หน้าแรกจึงให้เลือก "ประเภทที่พัก" แทนการเลือกอำเภอ

โครงงานนี้แยกไฟล์ตามหน้าที่ของแต่ละภาษา เพื่อให้เห็นชัดว่าภาษาใดทำหน้าที่อะไร

```
project/
├── index.html              HTML  — โครงสร้างหลักของเว็บไซต์
├── css/
│   └── style.css           CSS   — สี ตัวอักษร และการจัดวางเลย์เอาต์
├── js/
│   └── app.js              JS    — การโต้ตอบ การค้นหา การจอง การชำระเงิน
├── data/
│   ├── seed.json           JSON  — ข้อมูลตั้งต้นที่หน้าเว็บโหลดผ่าน fetch()
│   └── api-examples.json   JSON  — รูปแบบข้อมูลที่รับส่งกับเซิร์ฟเวอร์ทุกเส้นทาง
└── sql/
    └── sakon_stay.sql      SQL   — สร้างฐานข้อมูล 10 ตาราง ข้อมูลตัวอย่าง และคำสั่งดึงข้อมูล
```

## วิธีเปิดเว็บ

ไฟล์ `data/seed.json` ถูกอ่านด้วย `fetch()` เบราว์เซอร์จึงบล็อกถ้าเปิดไฟล์ตรง ๆ (`file://`)
ให้เปิดผ่านเว็บเซิร์ฟเวอร์แทน

```bash
cd project
python -m http.server 8000
```

แล้วเปิด <http://localhost:8000>
(หรือใช้ส่วนขยาย Live Server ของ VS Code / XAMPP ก็ได้)

## การไหลของข้อมูล

1. `index.html` วางโครงหน้าเว็บและเรียก `style.css` กับ `app.js`
2. `app.js` เรียก `fetch('data/seed.json')` แล้วแปลงเป็นออบเจกต์ด้วย `JSON.parse`
3. ข้อมูลที่แก้ไขระหว่างใช้งานถูกเก็บไว้ที่ `localStorage` เป็นข้อความ JSON
4. เมื่อต่อเซิร์ฟเวอร์จริง ให้แทนฟังก์ชันในอ็อบเจกต์ `api` ด้วยการเรียก REST ตามรูปแบบใน `data/api-examples.json`
5. ฝั่งเซิร์ฟเวอร์อ่าน-เขียนฐานข้อมูลตามสคีมาใน `sql/sakon_stay.sql`

## จุดเชื่อมต่อเซิร์ฟเวอร์

ฟังก์ชันที่ต้องแก้เมื่อเปลี่ยนไปใช้ฐานข้อมูลจริง อยู่ใน `app.js` ส่วน `const api = { ... }`
เช่น

```js
async login(username, password, role){
  const res = await fetch('/api/auth/login', {
    method:'POST',
    headers:{'Content-Type':'application/json'},
    body: JSON.stringify({username, password, role})
  });
  return await res.json();
}
```

## ฐานข้อมูล

`sql/sakon_stay.sql` สร้างฐานข้อมูล `sakon_booking` ตามเอกสารออกแบบ 8 ตาราง

| ตาราง | หน้าที่ |
|---|---|
| `User` | สมาชิกผู้จองที่พัก |
| `Admin` | ผู้ดูแลระบบ |
| `Property_Owner` | เจ้าของที่พัก |
| `Accommodation` | ที่พัก (`type` จำกัด 4 ประเภท, `district` บังคับเป็น เมืองสกลนคร) |
| `Room` | ห้องพักของแต่ละที่พัก |
| `Booking` | การจองและสถานะการชำระเงิน |
| `News` | ข่าวสาร โปรโมชั่น ประกาศ |
| `Review` | รีวิวและคะแนนจากผู้เข้าพัก |

นำเข้าด้วย

```bash
mysql -u root -p < sql/sakon_stay.sql
```

สิ่งที่เพิ่มจากเอกสารต้นฉบับ (ทำเครื่องหมาย "เสริม" ไว้ในไฟล์ SQL)

- `Room.accommodation_id` เป็นคีย์นอกไปยัง `Accommodation` เพราะของเดิมอ้างถึงที่พักด้วยชื่อเท่านั้น
- `Accommodation.district` + `CHECK (district = 'เมืองสกลนคร')` และ `type` แบบ ENUM 4 ค่า เพื่อบังคับเงื่อนไขของระบบ
- คอลัมน์ `username` / `email` ของผู้ใช้ และ `pay_status` / `slip_path` ของการจอง เพราะหน้าเว็บต้องใช้
