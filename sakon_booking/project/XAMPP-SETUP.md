# วิธีเชื่อมต่อกับฐานข้อมูลผ่าน XAMPP

โปรเจกต์นี้เชื่อมกับฐานข้อมูล **MySQL จริง** แล้ว ผ่านไฟล์ PHP ในโฟลเดอร์ `api/`
ทุกการกระทำในเว็บ (เข้าสู่ระบบ, สมัครสมาชิก, จองห้อง, จ่ายเงิน, รีวิว, อนุมัติที่พัก ฯลฯ)
จะถูกบันทึกลงตาราง MySQL จริง ไม่ใช่แค่ localStorage อีกต่อไป

## ขั้นตอนติดตั้ง

1. **เปิด XAMPP Control Panel** แล้วกด **Start** ที่บรรทัด `Apache` และ `MySQL`

2. **คัดลอกโฟลเดอร์ `project` ทั้งโฟลเดอร์** ไปไว้ใน htdocs ของ XAMPP เช่น
   - Windows: `C:\xampp\htdocs\sakon-stay\`
   - macOS/Linux: `/Applications/XAMPP/htdocs/sakon-stay/` หรือ `/opt/lampp/htdocs/sakon-stay/`

   (เอาแค่เนื้อไฟล์ข้างในโฟลเดอร์ `project` ไปวาง ไม่ต้องมีโฟลเดอร์ `project` ซ้อนอีกชั้นก็ได้)

3. **สร้างฐานข้อมูล** เปิดเบราว์เซอร์ไปที่ <http://localhost/phpmyadmin>
   - คลิกแท็บ **Import**
   - เลือกไฟล์ `sql/sakon_stay_xampp.sql` (ไฟล์นี้เป็นเวอร์ชันที่อัปเดตแล้ว ใช้แทน `sakon_stay.sql` เดิม)
   - กด **Go** — ระบบจะสร้างฐานข้อมูลชื่อ `sakon_booking` พร้อมข้อมูลตัวอย่างให้อัตโนมัติ

4. **ตรวจสอบรหัสผ่าน MySQL** ถ้าเครื่องคุณตั้งรหัสผ่านให้ root ไว้ (ปกติ XAMPP ไม่ตั้ง)
   ให้แก้ไขค่านี้ในไฟล์ `api/config.php`:
   ```php
   $DB_USER = 'root';
   $DB_PASS = '';   // ใส่รหัสผ่านของคุณตรงนี้ถ้ามี
   ```

5. **เปิดเว็บผ่าน Apache** (ห้ามดับเบิลคลิกไฟล์ `index.html` ตรง ๆ)
   ไปที่ <http://localhost/sakon-stay/>

เท่านี้เว็บก็จะอ่าน-เขียนข้อมูลกับ MySQL จริงผ่าน `api/get_data.php` และ `api/save_data.php`

## ตรวจสอบว่าเชื่อมสำเร็จ

- ลองเข้าสู่ระบบด้วยบัญชีทดสอบ (username `admin` / `owner` / `user`, รหัสผ่าน `1234`)
- ลองจองห้องพักหรือแก้ไขข้อมูล แล้วเปิด phpMyAdmin ไปดูตาราง `Booking` หรือ `Accommodation`
  ในฐานข้อมูล `sakon_booking` — ควรเห็นแถวข้อมูลใหม่ปรากฏขึ้นจริง

## โครงสร้างการเชื่อมต่อ (สำหรับผู้ที่ต้องการเข้าใจโค้ด)

| ไฟล์ | หน้าที่ |
|---|---|
| `api/config.php` | ตั้งค่าการเชื่อมต่อ MySQL ด้วย PDO |
| `api/get_data.php` | อ่านข้อมูลทุกตารางแล้วประกอบเป็น JSON รูปแบบเดียวกับ `data/seed.json` เดิม (เรียกด้วย GET) |
| `api/save_data.php` | รับข้อมูลทั้งก้อนจากเว็บ แล้วเขียนทับลงฐานข้อมูลใน 1 ธุรกรรม (เรียกด้วย POST) |
| `sql/sakon_stay_xampp.sql` | สคีมาที่เพิ่มคอลัมน์ `public_id`, `amenities`, `photos` จากไฟล์เดิม เพื่อให้ id ที่ฝั่งเว็บสร้างเองยังอ้างอิงแถวเดิมได้ทุกครั้งที่บันทึก |

ฝั่ง `js/app.js` ถูกแก้ 2 จุด:
- `fetchSeed()` เปลี่ยนจากอ่าน `data/seed.json` เป็นเรียก `api/get_data.php`
- `save()` นอกจากบันทึกลง `localStorage` แล้ว จะยิง POST ข้อมูลทั้งก้อนไปที่ `api/save_data.php` ทุกครั้งที่มีการเปลี่ยนแปลงข้อมูล (จอง, ยกเลิก, อนุมัติ, รีวิว, แก้ไขที่พัก/ห้องพัก ฯลฯ)

> หมายเหตุ: เว็บยังคงเก็บสำเนาข้อมูลไว้ใน `localStorage` ของเบราว์เซอร์เพื่อความเร็วเหมือนเดิม แต่ทุกครั้งที่บันทึกจะซิงก์ขึ้น MySQL ด้วยเสมอ ถ้าต้องการบังคับให้ดึงข้อมูลล่าสุดจากฐานข้อมูลจริง ให้ล้าง localStorage ของเบราว์เซอร์ (Dev Tools > Application > Local Storage) แล้วรีเฟรชหน้า

## อัปเดตใหม่: QR พร้อมเพย์จริง · ห้องคงเหลือ · ดาวเฉลี่ย

### 1) QR พร้อมเพย์ที่สแกนจ่ายได้จริง
- เจ้าของที่พักต้องกรอก **เลขพร้อมเพย์** ในฟอร์ม "เพิ่ม/แก้ไขที่พัก" (เบอร์มือถือ 10 หลัก / เลขบัตรประชาชน 13 หลัก / e-Wallet 15 หลัก)
- หน้าชำระเงินสร้าง QR มาตรฐานพร้อมเพย์ (EMVCo + CRC16) **พร้อมยอดเงินฝังอยู่ใน QR** เปิดแอปธนาคารสแกนแล้วยอดขึ้นเอง เงินเข้าบัญชีเจ้าของที่พัก
- ไฟล์ที่เกี่ยวข้อง: `js/qr.js` (ทำงานออฟไลน์ ไม่ต้องใช้ไลบรารีภายนอก)
- ที่พักที่ยังไม่ได้ตั้งเลขพร้อมเพย์ จะแสดงข้อความแจ้งแทน QR (ที่พักตัวอย่างต้องเข้าไปแก้ไขใส่เลขพร้อมเพย์ก่อน)
- ผู้จองต้องแนบ **ไฟล์รูปสลิปจริง** จึงจะส่งหลักฐานได้ และเจ้าของที่พักกดยืนยัน/ปฏิเสธในแท็บ "การชำระเงิน"

### 2) จำนวนห้องคงเหลือ
- **ห้องว่าง = จำนวนห้องทั้งหมด − ห้องที่ชำระเงินแล้ว** (ส่งสลิปแล้วหรือเจ้าของยืนยันแล้ว)
- จองแต่ยังไม่จ่ายจะยังไม่หักห้อง แต่แสดง "รอชำระ N" ให้เห็น
- ห้องจะถูกคืนอัตโนมัติเมื่อยกเลิกการจอง, เจ้าของปฏิเสธสลิป หรือสถานะการจองเป็น "เสร็จสิ้น"
- ตอนกดส่งสลิป ระบบดึงข้อมูลล่าสุดจากฐานข้อมูลแล้วตรวจอีกครั้งว่าห้องยังพอ (ป้องกันจองเกิน)
- ฐานข้อมูลเก็บค่าไว้ที่คอลัมน์ `Room.room_available`

### 3) ดาวเฉลี่ย (สูงสุด 5 ดาว)
- ผู้จองให้ดาว 1–5 ได้หลังสถานะการจองเป็น "เสร็จสิ้น" (1 การจองรีวิวได้ 1 ครั้ง)
- ค่าเฉลี่ย = ผลรวมดาวทุกรีวิว ÷ จำนวนรีวิว แสดงทศนิยม 1 ตำแหน่ง (เช่น 4.5/5) พร้อมดาวเติมสีตามสัดส่วน และกราฟจำนวนรีวิวแยกตามดาว
- ฐานข้อมูลเก็บ `Accommodation.rating_avg` และ `Accommodation.review_count`

> ฐานข้อมูลเดิมที่ import ไว้แล้ว **ไม่ต้อง import ใหม่** `api/config.php` จะเพิ่มคอลัมน์ที่จำเป็นให้เองในการเรียกครั้งแรก
